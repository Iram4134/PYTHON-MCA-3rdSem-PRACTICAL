**# MCA Semester-3 – Python Programs (List-1)

This repository contains Python programs based on basic programming concepts, lists, tuples, sets, dictionaries, and frozen sets.

## 📚 Programs

### 1. Fibonacci Numbers – Even Terms
Write a Python program to generate the first `n` Fibonacci numbers and print only the even terms.

### 2. Prime Factors
Write a Python program to input a number and print all its prime factors using loops.

### 3. String Operations – Reverse, Vowels & Palindrome
Write a Python program to:
- Reverse a given string
- Count the number of vowels
- Check whether the string is a palindrome

### 4. Even and Odd Numbers
Write a Python program to print all even and odd numbers between `1` and `50` using loops and conditional statements.

### 5. Remove Punctuation
Write a Python program to remove all punctuation characters from a given string.

### 6. Mixed Data-Type List
Create a list containing different data types and perform the following operations:
- Display all elements and their data types
- Find the length of the list
- Access elements using indexing and slicing
- Add elements
- Update elements
- Remove elements

### 7. Merge, Sort and Count Frequency
Write a Python program to:
- Merge two lists
- Sort the merged list
- Count the frequency of each element in the merged list

### 8. Tuple Operations
Create a tuple containing different data types and perform the following operations:
- Display all elements and their data types
- Access elements using indexing and slicing
- Find the length of the tuple
- Count the occurrences of a given element
- Find the index of a specified element

### 9. Set Operations
Create a set from a list containing duplicate elements and perform the following operations:
- Remove duplicate elements
- Add elements
- Remove elements
- Find the union of two sets
- Find the intersection of two sets
- Find the difference of two sets

### 10. Student Marks Dictionary
Create a dictionary containing student names and their marks and perform the following operations:
- Display all keys and values
- Add a new key-value pair
- Update an existing value
- Delete a key-value pair
- Find the student with the highest marks
- Calculate the average marks

### 11. Frozen Set Operations
Write a Python program to create a frozen set of numbers and perform the following operations with another set:
- Union
- Intersection
- Difference
